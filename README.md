# 🐙 깃싱크 (GitSync) - 초간편 한글 GitHub 폴더 동기화 프로그램

GitHub Desktop이 영어로 되어 있고 복잡하셨던 분들을 위해 만든 **초간단 100% 한글 GUI 동기화 프로그램**입니다.  
내 컴퓨터의 특정 폴더(바탕화면, 내 문서 등)와 GitHub 저장소를 클릭 한 번으로 손쉽게 동기화할 수 있습니다.

---

## 🌟 주요 특징 및 장점

1. **완벽한 한글 지원 & 모던 UI**
   - 모든 메뉴, 안내 문구, 오류 메시지가 친절한 한국어로 표시됩니다.
   - 윈도우 다크 모드 / 라이트 모드를 완벽 지원합니다.

2. **복잡한 Git 설정 자동화**
   - 시스템 환경변수(PATH)에 Git이 없어도, 컴퓨터에 설치된 Git(GitHub Desktop 내장 Git 포함)을 **스스로 감지하여 작동**합니다.
   - `git init`, `git add`, `git commit`, `git push`, `git pull` 등의 복잡한 터미널 명령어를 알 필요가 없습니다.

3. **내 저장소 원클릭 불러오기 & 새 저장소 생성**
   - GitHub 아이디와 토큰을 넣고 **[연결 & 저장소 불러오기]**를 누르면 내 GitHub에 있는 저장소 목록을 자동으로 콤보박스에 가져옵니다.
   - GitHub 웹사이트에 들어가지 않고도 프로그램 안에서 **[➕ 새 저장소]**를 즉시 만들어 바로 동기화할 수 있습니다.

4. **3가지 편리한 동기화 버튼**
   - 🚀 **원클릭 전체 동기화**: GitHub의 최신 변경사항을 내려받고(Pull), 내 컴퓨터의 새로운 파일들을 안전하게 업로드(Push)합니다.
   - ⬇️ **내려받기만 (Pull)**: GitHub에 있는 최신 파일들을 내 컴퓨터 폴더로 가져옵니다.
   - ⬆️ **올리기만 (Push)**: 내 컴퓨터 폴더에 있는 파일들을 GitHub에 저장합니다.

5. **주기적 자동 동기화**
   - 3분, 5분, 10분, 30분, 60분 간격으로 백그라운드에서 자동으로 파일을 동기화하도록 설정할 수 있습니다.

---

## 🚀 빠른 시작 가이드 (3단계)

### 1단계: 프로그램 실행
바탕화면에 생성된 **`깃싱크 (GitHub 동기화)`** 아이콘을 더블 클릭하여 실행합니다.  
(또는 `c:\Users\izaxi9\Desktop\anti\gith\GitSync.bat` 실행)

### 2단계: 계정 연결 (토큰 입력)
> 💡 **참고: 왜 일반 비밀번호가 아니라 토큰을 사용하나요?**  
> GitHub 정책상 2021년 8월부터 보안 강화를 위해 일반 계정 비밀번호 직접 로그인을 금지하고, 비밀번호 자리에 **개인 액세스 토큰(Personal Access Token, PAT)**을 사용하도록 의무화되었습니다.

1. 프로그램에서 **[🔑 토큰 발급 가이드]** 버튼을 누르거나, 아래 링크를 클릭합니다:  
   👉 [GitHub 토큰 생성 페이지 바로가기 (클릭)](https://github.com/settings/tokens/new?description=GitSync_App&scopes=repo)
2. 열린 브라우저 창 맨 아래로 스크롤하여 초록색 **[Generate token]** 버튼을 클릭합니다.
3. 화면에 생성된 `ghp_...` 로 시작하는 문자열을 복사합니다.
4. 프로그램의 **GitHub 아이디**와 **개인 토큰** 입력칸에 붙여넣은 후, **[🔗 연결 & 저장소 불러오기]** 버튼을 누릅니다!

### 3단계: 폴더 선택 후 동기화!
1. **[📁 폴더 선택...]**을 눌러 동기화하고 싶은 컴퓨터의 폴더(예: 바탕화면의 폴더)를 선택합니다.
2. **GitHub 저장소** 목록에서 연결할 저장소를 선택하거나, **[➕ 새 저장소]** 버튼으로 새로 만듭니다.
3. 가운데 파란색 **[🚀 원클릭 전체 동기화]** 버튼을 누르면 끝!

## 📁 파일 구조

- `깃싱크.exe`: **독립 실행형 Windows 단일 실행 파일 (더블 클릭만으로 바로 실행)**
- `app.py`: 메인 GUI 프로그램 소스 코드 (CustomTkinter 기반)
- `git_engine.py`: Git 실행 및 푸시/풀/동기화 처리 엔진 (자동 Git 경로 탐색)
- `github_api.py`: GitHub REST API 연동 (사용자 확인, 저장소 목록, 새 저장소 생성)
- `config_manager.py`: 사용자 설정 저장 및 로드 (`config.json`)
- `app_icon.ico`: 전용 고해상도 앱 아이콘
- `GitSync.bat`: 검은 콘솔 창 없이 앱을 실행하는 레거시 런처
- `GitSync_디버그.bat`: 오류 발생 시 디버그 로그를 볼 수 있는 콘솔 실행기
