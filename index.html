🐙 깃싱크 (GitSync)

복잡한 Git 명령어 없이 버튼 클릭 한 번으로 내 컴퓨터 폴더와 GitHub를 동기화하세요.
별도 설치 과정 없이 실행 파일 하나로 바로 사용할 수 있습니다.

📥 최신 버전 즉시 다운로드 (깃싱크.exe) GitHub 저장소 및 소스 코드 보기 →

💡 처음 실행 시 꼭 확인해 주세요!

1. Windows 보안 경고(PC 보호) 창이 뜰 때
개인 개발자 배포 파일 특성상 파란색 경고 창이 나타날 수 있습니다.
창 왼쪽의 [추가 정보] 글자를 누른 뒤 아래에 생기는 [실행] 버튼을 누르시면 정상 실행됩니다.
2. 사전 준비물: PC에 Git 설치하기
내 컴퓨터에 Git(또는 GitHub Desktop)이 설치되어 있어야 동기화가 작동합니다. 처음 쓰시는 분은 윈도우 검색창에서 cmd를 실행한 뒤 아래 명령어를 입력해 설치해 주세요.
winget install Git.Git
